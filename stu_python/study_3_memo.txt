アフィン変換は入力変数Xに、重みWを掛けバイアスbを足し合わせることで新たな変数Yへと変換する。
イメージとしては、
x = (x, y);

W = (W1, W2, 
     W3, W4);

b = (b1, b2);
とし、ｘをＸ座標,ｙをＹ座標としたグラフを考えると、

W1はＸの拡大率、W4はＹの拡大率、
W2はＸのせん断(斜めの歪み)、W3はYのせん断、
b1はX軸方向の平行移動、b2はY方向の平行移動

それぞれに対応しており、グラフ上にx,yに対応した点集合で何らかの図形を表示しているとき、
W,bにより拡大縮小、歪み、平行移動などの操作を行うことができ、新しい図形を得られる。

ReLUによる非線形性の付与について、
上記の計算はすべて線形でありスタートから何回アフィン変換を適応したとしても、
(仮に100億回でも)その最終地点はスタートから任意の1回の線形変換で到達可能であるため、
間のすべての計算/操作が無駄になる。
そこでReLU[if(x < 0) return 0; else if(x >= 0) return x;]などにより計算過程で非線形性を付与することで
複雑な境界線を引けるようになるというイメージである。

AIにこれらの「アフィン変換/非線形性の付与」が画像認識AIと如何に関係しているのかを聞くと、

アフィン変換 -> 取得した特徴量に重要性による重みを掛け前提などによるバイアスを足し合わせることで
画像から得られた情報を特定の何かへと判断するために有効なものへと作り変えるもの
ex)ねこの画像について、耳がある->(重み * 3), ひげがある->(重み * 1.1)のように処理し猫の特徴と一致するかを判断していく。

非線形性の付与 -> これらの重みづけなどによる変換の中で生じた負の特徴量を切り捨てることでAIの判断をより鮮明にし、
学習速度と精度の向上が期待できるものである
ex)猫か否かを考えている中で明らかに猫でない特徴量(犬のみに当てはまる特徴)を取得したときにマイナスを得るのではなく
0として無視することで猫か否かに集中できる

というようなイメージを持っていれば良いという返答を得た。
