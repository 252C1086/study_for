# PDF Merger

Pythonで作成した、複数のPDFファイルを1つに結合するGUIツールです。

## Features

- PDFファイルの追加
- ドラッグ＆ドロップによるファイル追加
- ドラッグ操作による結合順の変更
- 選択したファイルの削除
- 保存先の指定
- 複数PDFの結合

## Technologies

- Python
- PySide6
- pypdf

## Usage

1. PDFファイルを追加します
2. 必要に応じてドラッグ＆ドロップで順番を変更します
3. 「結合」ボタンを押します
4. 保存先を指定すると、PDFが1つのファイルに結合されます

## Purpose

複数のPDFをまとめる作業を簡単に行えるようにすることを目的として制作しました。

GUIを用いることで、Pythonやコマンド操作に慣れていない方でも利用できるようにしています。
